| `fix(controller): start a crashed golden boot over instead of failing the Agent for good` | a golden boot that ends `GoldenActorCrashed` was terminal in the controller: Substrate (agent-substrate/substrate#1220) crashes the actor on every failed atelet Run and the template reconciler fails the ActorTemplate once with the recorded crash, and the controller only carried that verdict into `Ready=False` — so a worker pod replaced under the golden actor (the WorkerPool rolling while a Harness change recompiles every template, as in the 4.7.19 → 4.8.0 upgrade) left every AgentTemplate unrunnable until something else changed the Harness (giantswarm/giantswarm#37766). The crash does not tell an infrastructure cause from a workload that dies on every boot, so the controller retries every `GoldenActorCrashed` and lets the budget tell them apart.
