| `fix(session): end a working turn whose runtime stopped saving events` | a turn's events reach its task only through the gateway run that dispatched or observes it, so a runtime lost after the turn's first event (a spot reclaim, a worker roll) or a controller restarted mid-turn left the task `TASK_STATE_WORKING` for good: the instance kept it as its active task, refused every later message as a conflict, and every client showed a turn that never ends (giantswarm/giantswarm#37988). `SUBMITTED` had the dispatch grace period; `WORKING` had no bound.
