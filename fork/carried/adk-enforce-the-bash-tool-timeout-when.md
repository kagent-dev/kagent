| `fix(adk): enforce the bash tool timeout when a command leaves child processes behind` and `fix(adk): keep background jobs able to write output after the bash tool returns` | the Go ADK's bash tool killed only `bash` on timeout and waited for the pipes of whatever bash had started, so `sleep 8; echo done` under a 2 s timeout returned after 8 s and `sleep 6 & echo started` after 6 s: a long pipeline or a backgrounded server held the tool call open.
