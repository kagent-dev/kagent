| `fix(harness): let Claude's own git trust the session's mirrors` | The bare mirrors on a Session's read-only `/mirrors` mount belong to the volume's owner, and the `claude` Harness starts Claude Code as uid 65532. The setup clone trusted a mirror on its own command line only (`-c safe.directory=<mirror>`), so the agent's own `git clone /mirrors/<owner>/<repo>.git` failed on git's dubious-ownership check and any repository the setup had not cloned stayed unreachable. Claude Code's environment now carries `safe.directory=<mirrors>/*` through `GIT_CONFIG_COUNT` when the dispatch names a mirrors directory: no file is written, an entry already configured is kept, and nothing outside the mirrors is trusted.
